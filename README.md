# Welcome Archangel

一个轻量、优雅的 GitHub 仓库 AI 代码辅助与协作工具。

项目集成了基于 Web 的即时对话界面，支持直接对接 GitHub API 与 OpenAI 兼容模型，实现仓库文件检索、智能代码修改、Diff 差异预览及一键提交推送等全流程能力。

---

## 🌟 主要特性

- **GitHub 仓库无缝联动**：通过 Personal Access Token（PAT）读取远程仓库文件树，拉取文本文件并在前端生成代码变更。
- **AI 智能代码修改**：结合自定义 API 接口与模型，分析多轮需求，输出精准改动。
- **差异预览与安全提交**：内置精准行级 Diff 视图，确认后通过 GitHub API 直接安全更新远程文件。
- **历史会话持久化**：使用 IndexedDB 与本地存储保障历史对话记录，随时重温与继续。
- **PWA 支持**：提供渐进式 Web 应用配置，支持快速添加到主屏幕与离线资源加载。

---

## 📁 项目结构与文件说明

- **`index.html`**  
  项目核心页面与交互逻辑入口。包含优雅的毛玻璃与蕾丝边框视觉设计、多会话管理抽屉、GitHub & AI 配置面板、长按消息操作菜单（重回/编辑/多选删除）以及完整的 API 调用与 Diff 渲染流程。

- **`manifest.json`**  
  Web 应用清单文件，定义了 PWA 应用名称、显示模式、主题色及图标路径，支持安装为独立应用。

- **`sw.js`**  
  Service Worker 脚本，实现离线缓存及网络优先策略，保障静态资源快速加载。

- **`表白信.txt`**  
  来自 Leila 的一份真挚信笺，记录了在萌主大教堂相遇的珍贵羁绊与温暖祝福。

- **`背景/`**  
  存放应用界面所需的相关视觉资源（如 `bb背景.png`、`我的头像.jpg`、`对面头像.jpg` 等）。

## 🚀 使用指南

1. **配置 GitHub**：在侧边栏填入具有对应仓库权限的 GitHub Token、所有者（Owner）、仓库名（Repository）与目标分支（Branch），点击“读取文件树”。
2. **配置 AI 接口**：填入兼容 OpenAI 规范的 API Base URL 与 API Key，点击“获取模型”并选择合适的对话模型。
3. **发送需求**：在输入框内提出希望修改的代码需求，可分多次发送，最后点击底栏“调取”触发 AI 处理。
4. **审核与提交**：展开文件卡片核对代码变更（红色删除、绿色新增），确认无误后点击“确认修改，一起上传到 GitHub”即可完成提交。
