# Welcome Archangel

一个轻量级且兼具美观与实用性的 GitHub 智能代码工作空间与即时交互单页应用。

---

## 📁 项目文件结构与介绍

| 文件 / 路径 | 类型 | 说明 |
| :--- | :--- | :--- |
| `index.html` | 核心页面 | 应用的主入口与单页系统。内置了玻璃质感与蕾丝边框的优雅界面，集成了 GitHub 仓库内容读取、AI 模型驱动的代码改写与 Diff 审查、IndexedDB 会话持久化存储以及长按多选/编辑消息等交互功能。 |
| `manifest.json` | PWA 配置 | Web App Manifest 文件，定义了应用名称（Welcome Archangel）、显示模式（standalone）、主题配色及应用图标，支持安装到桌面或主屏幕离线启动。 |
| `表白信.txt` | 纪念信件 | Leila 写给好闺蜜的温柔信函，记录了来自萌主大教堂的相遇与长久相伴的珍贵心意。 |
| `背景/` | 静态资源 | 存放应用所需的静态图像资源，包含页面背景图 `bb背景.png` 以及双方头像图片 `我的头像.jpg`、`对面头像.jpg`。 |

---

## ✨ 主要功能特性

1. **GitHub 仓库深度集成**
   - 配置个人访问令牌（Token）、Owner、Repo 与分支后，可实时抓取完整仓库文件树（Blob 列表）。
   - AI 生成的代码变更可通过 GitHub Contents API 进行精准的 Diff 比对，并在用户确认后原子化上传推送到远端仓库。

2. **智能 AI 辅助工作流**
   - 支持配置兼容 OpenAI 标准的 API Base URL、Key 与模型列表。
   - 具备多轮分析推理能力：从文件列表中定位目标文件、读取内容、生成修改建议并产出标准化差异比较（Diff）展示。

3. **本地持久化与消息管理**
   - 使用浏览器原生的 `IndexedDB` 保存历史对话记录，刷新或重新打开亦可随时调取。
   - 消息气泡支持长按手势：可一键“重回”重试、原位就地编辑内容或进入多选批量删除模式。

4. **精致的视觉体验**
   - 采用精致的亚克力毛玻璃拟物化设计、细腻柔和的微交互动效与古典典雅的装饰边框，适配桌面与移动端安全区域。
